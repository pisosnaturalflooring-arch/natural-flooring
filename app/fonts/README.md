# Tipografías locales

Se incluyen archivos WOFF2 variables del subconjunto latino de las mismas
familias y versiones que Google Fonts entregaba al sitio. Cubren el español.
`app/layout.js` los carga con `next/font/local`, sin descargar fuentes durante
el build. Se mantienen las variables CSS, `display: swap` y la ausencia de
precarga de League Spartan.

Fuentes originales:

- [Arimo, v36](https://fonts.gstatic.com/s/arimo/v36/P5sMzZCDf9_T_10ZxCE.woff2), pesos 400–700.
- [Cabin, v35](https://fonts.gstatic.com/s/cabin/v35/u-4i0qWljRw-PfU81xCKCpdpbgZJl6Xvqdns.woff2), pesos 400–700.
- [League Spartan, v15](https://fonts.gstatic.com/s/leaguespartan/v15/kJEqBuEW6A0lliaV_m88ja5TwvZwLZk.woff2), pesos 100–900.

Cada familia incluye su licencia SIL Open Font License en este directorio.
